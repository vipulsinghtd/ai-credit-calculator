RT Personalization Personalization Suite
Real-Time Personalization delivers sub-second API responses with customer attributes from the RT Decision Engine. RT Profiles are collections of customer attributes held in the engine, measured as the 4th highest daily count per month. Personalization Calls are API calls returning up to 20 attributes per request.

RT Triggers Personalization & Engagement
Real-Time Triggers fire downstream actions (webhooks, messaging, journey entry) when streaming events meet defined criteria — with ~3 minute end-to-end latency. Incoming Events are streaming events ingested into the RT Decision Engine. Trigger Activations are outgoing events generated from the engine to external systems.
